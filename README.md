# ليفرور فاس | LIVLINK MA

منصة ويب متكاملة مبنية بـ React و Vite و Tailwind CSS تربط أصحاب المحلات والمطاعم بسائقي التوصيل (الليفرورات) في مدينة فاس وكافة المدن المغربية.

## المميزات الرئيسية
- **وضعان للاستخدام**: وضع صاحب المحل / المطعم ووضع الليفرور مع تبديل فوري.
- **تغطية شاملة للمدن المغربية**: دليل مفصل لجميع المدن والأحياء (فاس، الدار البيضاء، الرباط، مراكش، طنجة، أكادير، وغيرها).
- **خريطة تفاعلية (LIVLINK MAP)**: عرض مواقع المحلات والليفرورات وتحديد الموقع الجغرافي الحالي.
- **تتبع مسار التوصيل (Delivery Route Map)**: شاشة متابعة للمسار المباشر وتفاصيل الوقت والمسافة وتأكيد التوصيل.
- **تصفية وبحث متقدم**: فلترة فورية حسب المدينة، الحي، نوع المركبة، وطريقة الدفع.
- **تواصل فوري**: اتصال هاتفي مباشر ورسائل واتساب بنصوص ترحيبية جاهزة.
- **إدارة العروض والبيانات**: إمكانية نشر عروض عمل، تسجيل ملفات السائقين، والتحكم بالحالة أو حذف العروض.
- **دعم الوضع الليلي والنهاري**: مع واجهة عربية متوافقة مع الهواتف والشاشات المختلفة.

## التشغيل والتطوير
```bash
npm install
npm run dev
```
